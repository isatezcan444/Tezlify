## Kritik duzeltme
- `.env.production` degeri: `GATEWAY_ENCRYPTION_KEY="aca6ff..."` (tirnakli)
- Container env degeri: `aca6ff...` (tirnaksiz)
- Docker Compose v2 tirmaklari standart olarak cikararak parse eder.
- Python ile dogrudan karsilastirma: **TUM kaynaklar ayni anahtari iceriyor.**

## Shell karalistirmasi neden yanlis cikti?
`grep | cut -d= -f2-` tirmaklari da aldi -> 66 karakter.

`sha256sum` farkli hash uretti -> "farkli anahtar" yorumu yapildi.

- Gateway ve backend ayni dosyayi kullaniyor.
- Recreate = ayni anahtar, snapshot okunabilir.
